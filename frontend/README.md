# Frontend - Prediction Platform

React-based frontend for the Prediction Platform.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/        # Reusable components
├── pages/            # Page components
├── store/            # Redux store and slices
├── services/         # API and socket services
├── App.jsx           # Main app component
└── main.jsx          # Entry point
```
